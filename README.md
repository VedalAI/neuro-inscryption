# <img src="https://raw.githubusercontent.com/VedalAI/neuro-sdk/refs/heads/main/Assets/icon.png" width="29" style="vertical-align:middle;"> Neuro-sama Integration Mod for Inscryption
This mod allows [Neuro-sama](https://twitch.tv/vedal987) to play Inscryption by communicating with the game through a websocket.

Check out the [Neuro SDK](https://github.com/vedalai/neuro-sdk) to see how to create similar integrations for other games.
